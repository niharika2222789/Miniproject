 Vulnerability Analysis of Urban Slums for Disaster Preparedness

 Overview

This project is a web-based disaster management platform designed to identify and analyze vulnerable urban slum areas. The system helps improve disaster preparedness through vulnerability mapping, weather monitoring, emergency response support, risk analytics, and AI-based assistance.

 Features

* Vulnerability Mapping
* Real-Time Weather Monitoring
* AI-Based Disaster Assistance
* Emergency Response System
* Risk Analytics Dashboard
* Disaster History Records

 Technologies Used

* HTML
* CSS
* JavaScript
* Python
* FastAPI
* Google Maps API
* Open-Meteo API
* Gemini AI
 Future Scope

* Real-time disaster alerts
* Mobile application support
* Machine Learning based risk prediction
* IoT sensor integration
* Multi-language support
